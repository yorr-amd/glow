Fedora / RHEL / DNF Repository

🌸 Glow ✦ Skincare Companion

Repositori resmi Linux untuk instalasi dan pembaruan otomatis (1-klik di Discover & DNF).

1. Tambahkan Repositori ke Sistem Fedora / RHEL:

sudo curl -fsSL https://yorr-amd.github.io/glow/glow-tracker.repo -o /etc/yum.repos.d/glow-tracker.repo

2. Pasang Aplikasi:

sudo dnf install glow-tracker

3. Perbarui Kapan Saja:

sudo dnf upgrade glow-tracker

Atau cukup buka KDE Discover / GNOME Software, Glow akan otomatis terdaftar di tab Updates!
